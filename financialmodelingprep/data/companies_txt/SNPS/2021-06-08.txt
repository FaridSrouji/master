Synopsys Acquires Code Dx to Extend Application Security Portfolio. MOUNTAIN VIEW, CALIF., JUNE 8, 2021 /PRNEWSWIRE/ --  SYNOPSYS, INC. (NASDAQ: SNPS) TODAY ANNOUNCED THAT IT HAS ACQUIRED CODE DX, A PROVIDER OF AN AWARD-WINNING APPLICATION SECURITY RISK MANAGEMENT SOLUTION THAT AUTOMATES AND ACCELERATES THE DISCOVERY, PRIORITIZATION, AND REMEDIATION OF SOFTWARE VULNERABILITIES.

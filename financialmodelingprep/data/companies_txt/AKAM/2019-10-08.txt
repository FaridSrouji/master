Tech Data Forms Partnership with Akamai Technologies to Provide Defense-In-Depth Capabilities. Tech Data announced it has partnered with Akamai Technologies to offer security and performance services tailored to meet clients’ IT security needs as their businesses evolve. Representing Akamai’s first partnership with a technology distributor, these additions to Tech Data’s security portfolio provide a cloud- and data-center-agnostic delivery platform with a defense-in-depth approach, whereby a series of defensive mechanisms are layered for utmost data protection. Tech Data customers in the U.S. and Canada can now leverage any of the following three comprehensive Akamai solution packages: 1. Web application firewall protection 2. Accelerated performance of web and mobile applications 3. Enterprise traffic protection and remote application access. All services provided are cloud- and hosting-provider-agnostic, include a 100% uptime guarantee and integrate without significant changes to infrastructure and software at the end-user site. This solution set provides customers with a secure, reliable and flexible extension to their IT infrastructure and was named in Gartner's Magic Quadrant for Web Application Firewalls 2018.

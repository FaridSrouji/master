ORACLE OPENS HOSPITALITY API SPECIFICATIONS TO HELP INDUSTRY RECOVER. AUSTIN, TEXAS, MARCH 30, 2021 /PRNEWSWIRE/ -- THE PANDEMIC UNDERSCORED THE NEED FOR HOSPITALITY PROVIDERS TO HAVE FLEXIBLE SYSTEMS THAT CAN BE ADAPTED QUICKLY TO EXCEED CHANGING GUEST EXPECTATIONS. MAKING IT EASIER FOR PARTNERS TO ADAPT AND INNOVATE, ORACLE HAS MADE THE REST API SPECIFICATIONS IN THE ORACLE HOSPITALITY INTEGRATION PLATFORM (OHIP) FREELY ACCESSIBLE THROUGH GITHUB UNDER THE UNIVERSAL PERMISSIVE LICENSE (UPL) MODEL.

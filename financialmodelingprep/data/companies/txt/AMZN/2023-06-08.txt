GIGAMON ANNOUNCES DEEP OBSERVABILITY INTEGRATION WITH AMAZON SECURITY LAKE. SANTA CLARA, CALIF.--(BUSINESS WIRE)--GIGAMON, THE LEADING DEEP OBSERVABILITY COMPANY, TODAY ANNOUNCED THAT ITS DEEP OBSERVABILITY PIPELINE NOW EFFICIENTLY DELIVERS NETWORK-DERIVED APPLICATION METADATA INTELLIGENCE (AMI) INTO AMAZON SECURITY LAKE FROM AMAZON WEB SERVICES (AWS). AMAZON SECURITY LAKE AUTOMATICALLY CENTRALIZES AN ORGANIZATION'S SECURITY DATA FROM ACROSS THEIR AWS ENVIRONMENTS, LEADING SAAS PROVIDERS, ON-PREMISES ENVIRONMENTS, AND CLOUD SOURCES INTO A PURPOSE-BUILT DATA LAKE, SO CU.
